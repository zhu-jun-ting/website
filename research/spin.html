让历史文献，重新成为可读的数据。

Translating Optical Character Recognition Text to Words with the Reading Time Machine

研究海报 PDF ↗完整报告 PDF ↗

MY CONTRIBUTION

为 OCR 的错误，建立可比较的度量。

在 Jill Naiman 教授指导下，使用 Python 与 pytesseract 检查历史天文文献的识别结果，量化 WER / CER，并通过 Levenshtein 编辑操作分析常见字符错误与混淆对。

01 / METHOD

从扫描图像，到错误分布。

研究把扫描页、OCR 输出和人工参照文本联系起来。词错误率和字符错误率以替换、删除、插入操作衡量差异；再结合置信度检查与字符统计，定位容易出错的位置。

    历史天文论文图像

  2. 02Tesseract

    提取文字与置信度

  3. 03Ground truth

    对齐人工参照文本

  4. 04WER / CER

    错误率与字符频次

02 / FINDINGS

高置信度，也可能读错。

研究观察到数学公式、非同行字符容易被误识别；一些错误也发生在高置信度结果中，例如 “Fic” 与 “Fig”。在报告的默认运行中，句号与逗号的混淆值得进一步分析。

这项工作的主要成果是错误量化流程与错误模式观察。更多分辨率、文件格式、模型和配置的比较列为后续工作，不能视为已经验证的提升。
