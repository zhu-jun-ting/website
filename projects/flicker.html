PROJECT 01 / 独立游戏 · 教育交互2022–2023

Flicker

让汉字，在碰撞中被理解。

把汉字的构字关系转化为弹射与碰撞，让中文初学者通过尝试、组合和反馈认识新的字。

在线试玩 ↗演示视频 ↗开发记录 ↗完整作品集 PDF ↗
我的职责
独立策划、原型开发、视觉设计、玩家测试
方法与工具
Unity / C# / Figma / 实体原型
项目形式
Unity 原型 / 可在线体验

MY CONTRIBUTION

我在项目中做了什么。

从学习动机与构字法研究出发，独立完成玩法设计、木质字块测试、反馈整理和 Unity Demo。

个人项目；导师 Stacey Robinson、Emilie Butt

01 / QUESTION

记忆之外，能否让学习成为一次发现？

项目从重复记忆容易削弱学习动力的问题出发，把汉字由简单形体构成复杂字的过程，转化为可操作的游戏规则。玩家拖动、瞄准、弹射字块，通过碰撞尝试新的组合。

02 / PLAYTEST

先在桌面上，验证一个动作。

早期测试用激光切割的木质字块和桌面模拟场地。玩家反馈集中在瞄准困难、基础字块数量、难度和提示时机。设计据此提出轨迹预览、卡住时再出现的提示，以及更多组合与奖励的方向。

03 / PROTOTYPE

从纸面规则，走到可以操作的原型。

Unity 实现将字块、场地、效果层和 UI 分开组织。字块保存文字与组合信息，碰撞后显示新字、解释和得分；对象池管理具有物理效果的残影。现有成果是演示原型，文档中的扩展玩法并非全部实现。
